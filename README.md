## What Lives Here

hermes-kit is the lab bench. New ideas start here. When something proves itself useful, complete, and shareable, it graduates to its own repository.

## Design Principles

1. **Concrete over aspirational.** Every pattern discovered by fixing a real failure.
2. **Auditable over efficient.** An unverifiable pipeline is a fake pipeline.
3. **Who before how.** Defaulting to "I'll do it" is the most expensive bias in agent orchestration.
4. **Modular models.** No single model should be the bottleneck.
